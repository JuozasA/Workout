## WEDNESDAY — HIIT + Core

*Focus: Fat burning + rotational power (non-impact to protect tired legs)*

### Warm-up

- Bike — 3 min easy

### HIIT Block (10 rounds — Bike)

- Hard: 30 sec @ 90+ RPM, resistance 8-10
- Easy: 60 sec @ 60 RPM, low resistance

> Swapped from treadmill sprints to bike intervals. Mon's squats + RDL + Bulgarian split squats leave legs under-recovered by Wednesday; sprinting on fatigued legs is where hamstring strains happen. Same metabolic effect, no impact.

### Core Circuit — 3 Rounds

| # | Exercise                     | Reps / Time |
| - | ---------------------------- | ----------- |
| 1 | Cable Woodchop (high to low) | 10/side     |
| 2 | Cable Woodchop (low to high) | 10/side     |
| 3 | Plank with Shoulder Tap      | 10/side     |
| 4 | Hollow Body Hold             | 20 sec      |

Rest 60 sec between rounds

**Time: ~40 min**

## FRIDAY — Full Body Power & Integration

*Focus: Rotational power + weight transfer*

# SWING FIXES

| Your Issue                     | Exercise That Helps                              |
| ------------------------------ | ------------------------------------------------ |
| Hips turn too much on takeaway | 90/90 Hip Switches, Pallof Press, Dead Bug       |
| Arms/club get behind you       | Thread the Needle, Open Book, Thoracic Foam Roll |
| Body doesn't turn quick enough | Cable Woodchops, Half-Kneeling Rotation          |
| Lean behind ball               | Single Leg RDL, Bulgarian Split Squat            |
| Steep/tilted shoulder          | Lat Pulldown, Face Pulls                         |
| Poor weight transfer           | Deadlift, Farmers Walk, Single Leg work          |

---

# PROGRESSIVE OVERLOAD

Each week, aim for:

- +1-2 reps at same weight on main lifts
- +2.5kg when you hit top of rep range
- Longer hold on stability exercises (when used as stimulus, not activation)
- Higher RPM or resistance on HIIT intervals
